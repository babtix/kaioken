The TUI centers around the Model struct in tui.go, which holds application state and implements the Bubble Tea Update method to process user input and asynchronous results. Slash commands are registered in commands.go and routed via the dispatch method, with many commands (like research and impact prediction) launching background goroutines that communicate results via typed messages (e.g., impactMsg, doneMsg) on the m.events channel. The UI uses Lipgloss for styling, with themes defined in theme.go, and relies on Bubble Tea components (list, spinner, etc.) for interactive elements. Error handling is consistent, using m.appendLine with errStyle for failures and okStyle for success.
