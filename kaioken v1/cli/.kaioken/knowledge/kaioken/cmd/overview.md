The kaioken/cmd package provides the command-line entry point for the kaioken application. It defines the main function, parses commands and flags, and dispatches to subcommand implementations located in separate files (e.g., run.go for the 'run' and 'rpc' commands, ext.go for the 'ext' command). Each subcommand follows a consistent pattern of loading configuration, creating an LLM client if needed, and delegating to internal packages.
