The agent skills module uses the Go standard library (context, fmt, os, path/filepath, strings, sync, time, golang.org/x/sync/errgroup) and the third-party YAML library (gopkg.in/yaml.v3). It depends on several internal packages: agentsmd for updating the AGENTS.md file, codemap for building and querying code structure, config for configuration, llm for interacting with the language model, and scan for accessing scanned file information.
