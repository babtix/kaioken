The plan package defines Module and Plan structs to represent the knowledge module tree. The Generate function is the primary entry point: it constructs a prompt from the scan result's tree summary (via TreeSummary) and manifest contents (via ManifestContents), adds project notes from config, and uses the LLM client to obtain a module tree in JSON format. The resulting plan is validated against the scan result to warn about scope entries that don't match any scanned files (either as exact matches or directory prefixes), but validation never fails plan generation. The Plan type includes methods to persist (Save) and load (Load) the modules.yaml file in the repository's .kaioken directory (using config.Dir), to flatten the hierarchy for processing via Flatten, and to resolve a module's scope to concrete file paths via FilesFor. Dependencies flow inward: this package depends on kaioken/internal/config for directory constants, kaioken/internal/llm for the LLM client interface, and kaioken/internal/scan for the Repository scan result.
