The module centers around FileMap (representing a file's skeleton) and Index (repository-wide symbol map). Parse() in codemap.go dispatches to language-specific parsers (parseGo, parsePython, or parseCLike) based on file extension. Index.Build() parallelizes parsing via errgroup, populating Files map and a reverse symbol index for verification. Bundle() in bundle.go allocates token budget between structure (skeletons) and source (full bodies or selected declarations), ranking files by goal relevance using term matching and file priority (manifests, entry points, models, etc.). Symbols are sorted by line number; Exported() filters public surface; Skeletons include line anchors for citations.
