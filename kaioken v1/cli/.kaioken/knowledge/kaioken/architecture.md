The application’s entry point resides in ./cmd/kaioken (built as kaioken or kaioken.exe). It uses github.com/charmbracelet/bubbletea for the TUI loop and github.com/charmbracelet/bubbles for UI components, styled with github.com/charmbracelet/lipgloss. Terminal execution is handled through a pseudoterminal provided by github.com/UserExistsError/conpty and github.com/creack/pty, while clipboard access uses github.com/atotto/clipboard. Settings are loaded with gopkg.in/yaml.v3 (expected files such as Kaioken-settings-logo.json). Markdown content is rendered via github.com/yuin/goldmark, .gitignore parsing relies on github.com/sabhiram/go-gitignore, and optional WebAssembly execution uses github.com/tetratelabs/wazero. Dependency flow is unidirectional: the main package imports these libraries; there is no visible internal layering beyond the standard Go package structure.
