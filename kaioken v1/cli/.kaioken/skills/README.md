# Project Skills

Task-oriented guides for working in this repository, generated by Kaioken.
Each skill says how to perform one recurring task here — which files to
touch, in what order, and which local conventions apply.

Open the skill matching your task before you start.

## [add-a-cli-command](add-a-cli-command/SKILL.md)
Add a new command to the kaioken CLI. Load this skill when extending the command-line interface with new functionality.

## [add-a-skill](add-a-skill/SKILL.md)
Create a new skill file in the .kaioken/skills/ directory. Load this skill when you want to teach the agent a new task by defining a skill guide.

## [add-a-tui-command](add-a-tui-command/SKILL.md)
Add a new command to the TUI's command palette. Load this skill when you want to extend the interactive terminal interface with a new slash command.

## [build-the-binary](build-the-binary/SKILL.md)
Compile the kaioken executable. Load this skill after modifying source code to produce an updated binary.

## [generate-wiki-documentation](generate-wiki-documentation/SKILL.md)
Generate the wiki documentation for the repository. Load this skill after making changes to the source that should be reflected in the generated knowledge base.

## [lint-the-code](lint-the-code/SKILL.md)
Run golangci-lint to check for style issues and potential bugs. Load this skill as part of code quality checks.

## [run-the-test-suite](run-the-test-suite/SKILL.md)
Execute all unit tests for the project. Load this skill before committing changes or when verifying fixes.

## [update-dependencies](update-dependencies/SKILL.md)
Update Go dependencies to their latest versions and tidy the go.mod file. Load this skill when bringing in dependency updates.
