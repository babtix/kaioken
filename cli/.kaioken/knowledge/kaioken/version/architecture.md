The module consists of a single Go file, `internal/version/version.go`, defining package `version`. It contains two exported symbols: `var Version string` initialized to "1.3.3" and intended to be overridden at build time with `-ldflags "-X kaioken/internal/version.Version=..."`, and `const ContractVersion int = 4` representing the API contract version. There are no functions, interfaces, or dependencies; the package is purely a data holder that other packages import to access these values.
