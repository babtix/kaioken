The package defines two exported identifiers: var Version string and const ContractVersion int. Version is initialized to "0.1.0" and intended to be overwritten via linker flags during builds of the CLI or TUI. ContractVersion is set to 1 and updated manually when any /v1 API shape changes in a backward‑incompatible way. There are no internal dependencies, no init functions, and no error handling logic; the package is purely a data holder imported wherever version information is needed.
