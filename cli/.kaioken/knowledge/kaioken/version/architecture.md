The module consists of a single Go file, internal/version/version.go, defining the package version. It exports a variable Version (string) and a constant ContractVersion (int). Version is declared as a var so it can be overridden at build time via the -ldflags "-X kaioken/internal/version.Version=..." mechanism; ContractVersion is a const that is bumped when the API contract changes. No functions, initialization logic, or dependencies exist within the package. Other packages import version and read these values directly.
