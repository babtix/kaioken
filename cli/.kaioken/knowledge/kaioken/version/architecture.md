The module consists of a single Go file, internal/version/version.go, defining the package version. It exports two symbols: a variable Version (string) that is set at build time via -ldflags to allow overriding, and a constant ContractVersion (int) representing the API contract version. There are no imports, no external dependencies, and no internal functions or data structures; consumers simply import "kaioken/internal/version" and read these values.
