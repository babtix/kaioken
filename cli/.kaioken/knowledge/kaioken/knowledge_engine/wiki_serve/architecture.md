The module centers around the Server struct in serve.go, which holds the repository path and a configured goldmark.Markdown instance. The Run function initializes a TCP listener, creates an http.Server using Server.routes() as the handler, and manages graceful shutdown via context cancellation. Routing is handled by http.NewServeMux with three endpoints: '/' for the index (handleIndex), '/d/' for document serving (handleDoc), and '/search' for search functionality (handleSearch).

Document rendering follows a security-conscious flow: handleDoc uses Server.resolve to validate paths against the wiki root (preventing directory traversal), reads the file, enforces a maxDocBytes limit, and renders via the Server's goldmark instance. The page function assembles the final HTML by combining chrome (sidebar, breadcrumbs, pager, TOC) with the rendered body. The sidebar is built dynamically by Server.sections, which walks the wiki directory to create a nav tree of sections and documents. Search performs case-insensitive substring matching across all documents, highlighting matches with <mark> tags.

Error handling returns appropriate HTTP status codes: 404 for missing/invalid paths, 500 for render errors. The server has no authentication or caching mechanisms, relying on reading files directly from disk per request. Dependencies include the internal/wiki package for wiki directory resolution and goldmark for markdown-to-HTML conversion with table, strikethrough, and autolink extensions.
