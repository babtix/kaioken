The module is structured around a Go HTTP server defined in serve.go, which uses the goldmark library for markdown rendering. The server exposes routes for the index (/), document viewing (/d/), search (/search), and graph viewing (/graph and /graph.json). The graph view relies on an embedded JavaScript engine (from assets/graph.js, embedded via assets.go) that renders a force-directed graph of wiki nodes (documents, files, sections) and edges (contains, links, source). The server reads the wiki directory structure (via wiki.WikiDir) to build navigation sections and documents, and uses the wiki.BuildGraph function from the internal/wiki package to generate graph data. Key safety mechanisms include path resolution to prevent directory traversal (resolve function) and HTML escaping for user input. The graph page mounts the JavaScript engine, which fetches /graph.json and allows navigation to documents by clicking on doc nodes.
