The module centers around the Server type in serve.go, which handles HTTP requests via routes defined in the routes() method. The server uses goldmark for markdown conversion and depends on the internal/wiki package for wiki directory resolution and graph data generation. Key handlers include handleIndex for the overview page, handleDoc for individual documents (with path safety via resolve), handleSearch for full-text search, and handleGraphPage/handleGraphJSON for the interactive graph view. The graph view embeds a pre-built force-graph engine (from assets/graph.js) that is bootstrapped to fetch graph data from /graph.json. Static site generation is handled by the Export function in static.go, which reuses the same rendering logic as the HTTP server but writes output to files and uses relative links. The server and static export share the page rendering core to ensure consistency. Error handling returns 404 for missing or out-of-wiki paths and 500 for internal rendering errors. The server shuts down gracefully on context cancellation.
