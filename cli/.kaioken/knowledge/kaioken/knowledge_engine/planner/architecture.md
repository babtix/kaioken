The plan package defines Module, Plan, and FlatModule types to represent the hierarchical module structure. It depends on the config, llm, and scan packages. The Generate function constructs an LLM prompt using the scan result's tree summary (limited to 12 files per directory) and manifest contents (limited to 4000 bytes per manifest), plus any config notes, then calls the LLM client to produce a module tree. The Validate function checks each module's scope entries against the scan result's file set, warning about non-matching entries (exact path or directory prefix). The Save function writes the plan to <repo>/.kaioken/modules.yaml (via config.Dir) with a header comment, creating the directory if needed. Load reads and unmarshals the existing plan. Flatten returns modules in parent-before-children order with hierarchical IDs joined by '/'. FilesFor returns the deduplicated, scan-ordered file list matching a module's scope.
