The module uses Go standard libraries (context, fmt, os, path/filepath, sort, strings, sync, time) and internal packages: kaioken/internal/config for configuration, kaioken/internal/scan for repository scanning, kaioken/internal/codemap for code structure indexing, kaioken/internal/llm for language model interactions, kaioken/internal/gitx for git operations in update.go, and gopkg.in/yaml.v3 for YAML serialization of outlines and stamps.
