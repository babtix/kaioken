The module uses Go standard library (context, fmt, os, path/filepath, sort, strings, sync, time, golang.org/x/sync/errgroup, gopkg.in/yaml.v3) and internal Kaioken packages: codemap for code structure indexing, config for configuration, llm for LLM client interactions, scan for repository scanning, gitx for git operations. It relies on external LLMs via the llm.Client interface for all generative passes (outline, brief, subplan, document generation, critique, correction, changelog). Regex patterns in facts.go and polish.go handle language-specific fact extraction and Mermaid validation.
