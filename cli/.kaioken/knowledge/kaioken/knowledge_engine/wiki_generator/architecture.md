The module centers around wiki.go's Run function orchestrating five passes: (1) indexing code structure via codemap.Build, (2) generating/loading global outline (OutlinePath) via LLM using outlineSystem, (3) loading/building shared architecture brief (BriefPath) via LLM using briefSystem, (4) per-section sub-planning and document generation with quality passes, (5) post-processing via sanitizeMermaid and crossLink. Key mechanisms include: facts.go's detectFacts extracting framework facts (routes/models/commands/env) using language-specific regex and codemap.Index, cached per repo; provenance.go's stampProvenance embedding machine-readable source file footers in documents for incremental updates; update.go's Update function revising only documents affected by git diffs using Stamp (.kaioken/wiki_state.yaml) baseline; verify.go's verify checking documents against codemap.Index to catch hallucinated files/symbols/anchors/excerpts. Concurrency is managed via errgroup with config-driven limits to avoid rate limits.
