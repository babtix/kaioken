The module centers around main.go's main function, which sets up signal handling, parses flags via a custom flags struct and parseFlags function, and routes to subcommand handlers (e.g., cmdInit, cmdScan). Subcommands are implemented as functions in main.go or separate files (ext.go, index.go, mcp.go, review.go, usage.go) and delegate work to internal packages (e.g., internal/generate for knowledge cards, internal/ext for extensions). Error handling is centralized: subcommands return errors that main prints before exiting with status 1. Usage tracking occurs via trackSpend and bookSpend to record LLM usage even for failed runs. The flags struct captures common options (-repo, -model, etc.) and positionals, while subcommands with additional flags (like mcp and review) parse them from positionals or via dedicated parsers (parseMCPFlags).
