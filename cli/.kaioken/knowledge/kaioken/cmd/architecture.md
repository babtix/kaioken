The main() function in cmd/kaioken/main.go serves as the entry point. It first cleans up old update backups via selfupdate.CleanupOld(), then checks for updates interactively via updateNotice(). It parses the command (os.Args[1]) and remaining arguments into a flags struct using parseFlags(). A signal-handled context is created for graceful shutdown. The command is dispatched to a corresponding function (e.g., cmdRun for 'run', cmdInit for 'init') defined in separate files. Each command function receives a context.Context and the flags struct, performs its work via internal packages, and returns an error. After execution, bookSpend() records usage metrics. Errors are handled specially: errStale (from status -check) exits with code 1; *cliExit uses its exit code; other errors print and exit with code 1. Common flags (-repo, -model, etc.) are parsed by parseFlags() into the flags struct; command-specific flags are handled within each command function (e.g., run command processes -p, -mode, -approve, -jsonOut).
