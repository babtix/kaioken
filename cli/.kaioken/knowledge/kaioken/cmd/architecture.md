The module consists of multiple Go files in cmd/kaioken, each handling one or more subcommands. Main entry point is in main.go, which sets up signal context, cleans up old binaries, parses command/args via parseFlags, and dispatches to command-specific functions (e.g., cmdRun, cmdExt). Command functions load config, create LLM client via newClient (which tracks usage), and delegate to internal packages (agent, gitdraft, handoff, etc.). Error handling is centralized in main.go: errStale (from status.go) triggers exit 1, *cliExit triggers custom exit code, other errors print 'error:' and exit 1. Usage tracking uses trackSpend (usage.go) and bookSpend (main.go) to record LLM API usage.
