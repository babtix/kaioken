The module consists of multiple Go source files in the cmd/kaioken directory, with main.go serving as the entry point. The main function in main.go sets up signal handling, checks for update notices, and parses the command line arguments. It then dispatches to command-specific handler functions (e.g., cmdRun, cmdInit, cmdExt) based on the first argument. These handlers are defined across the files in this directory, with some in main.go and others in separate files named after the command (e.g., ext.go for the ext command).

Each handler function receives a context.Context and a flags struct (parsed by parseFlags in main.go) containing common flags like -repo, -model, -force, etc. Command-specific flags and positionals are parsed within the handler. The handlers interact with internal packages (e.g., internal/config, internal/generate, internal/llm) to perform the actual work. Error handling is centralized in main: after a handler returns, main checks for specific errors (like errStale for stale knowledge) and either exits with an appropriate code or prints the error and exits with code 1. Usage tracking is performed by calling bookSpend before exiting, which records the LLM usage for the command.
