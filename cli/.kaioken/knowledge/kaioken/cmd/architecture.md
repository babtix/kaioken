The main function in cmd/kaioken/main.go initializes the application by cleaning up old binaries, checking for updates in interactive mode, and parsing the command-line arguments. It sets up a signal-handling context and dispatches to the appropriate subcommand function based on the first argument (defaulting to the tui command if no command is provided).

Each subcommand is implemented in a file named after the command (or a group of related commands, such as ext.go for the 'ext' command and its subcommands). Subcommand functions follow the signature func cmd<CommandName>(ctx context.Context, f flags) error, where the flags struct (parsed by parseFlags in main.go) contains common flags like -repo, -model, -module, -force, -token, -out, -base, and -approve. The function typically loads configuration, creates an LLM client (if required), and calls into internal packages to perform the work.

Error handling is centralized: subcommand functions return errors, which main prints to stderr and exits with a non-zero code. Special handling exists for the status command's --check flag, which returns a sentinel error (errStale) to indicate stale knowledge without an error message. Output is directed to stdout for human-readable results or to a file via the -out flag, with JSON output enabled by the -json flag.

Common helper functions in main.go include parseResearchArgs for parsing research multipliers, slugify for generating filenames, splitComma and splitAndTrim for parsing comma-separated lists, and formatBytes for formatting byte sizes.
