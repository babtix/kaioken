The module consists of two source files: main.go and ext.go. main.go contains the main function, a custom flags parser (flags struct and parseFlags function), and implementations for most commands (tui, init, scan, plan, wiki, update, generate, skills, export, serve, hook, daemon, status, models, logo, version, help). ext.go contains the ext command and its subcommands (install, dev, validate, remove, update, search, enable/disable, trust/untrust, tools). Command functions follow a pattern: those requiring context for cancellation or long-running work (e.g., plan, wiki, update, generate, skills, serve, daemon, models, ext) take context.Context and flags; quick operations (scan, export, hook, status, logo, version, help, tui) take only flags. All command functions return an error handled in main. The flags struct parses -key value pairs and boolean flags, with positionals capturing multiple arguments for subcommands like ext. Dependencies flow from cmd to internal packages (config, scan, llm, etc.), with no external frameworks beyond the Go standard library.
