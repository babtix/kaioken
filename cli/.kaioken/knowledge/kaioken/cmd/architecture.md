The main entry point is in main.go where the main function processes command-line arguments, sets up a context for signal handling, and routes to command-specific functions (e.g., cmdRun, cmdRPC, cmdInit) based on the first argument. Each command function resides in its own file (e.g., run.go for run and rpc, ext.go for ext) and follows a pattern of loading configuration, initializing an LLM client via newClient, and executing the command's core logic. Error handling in main distinguishes between stale state (exit 1 without 'error:' prefix) and other errors (printed with 'error:' prefix and exit 1). The flags struct in main.go parses common flags (-repo, -model, etc.) and command-specific arguments are accessed via positionals or parsed within the command function. Usage tracking is performed via bookSpend after command execution, even on error.
