The module centers around main() in cmd/kaioken/main.go, which first cleans up old binaries via selfupdate.CleanupOld(). If no command is provided, it launches the TUI via tui.Run(). Otherwise, it parses flags into a flags struct, sets up interrupt signal handling, and uses a switch statement to route to command functions (cmdInit, cmdScan, etc.). Each command function typically loads config, creates an LLM client via newClient(), and delegates to internal packages (scan, plan, generate, wiki, etc.). The ext command is handled separately in cmd/kaioken/ext.go, which parses subcommands from flags.positionals and dispatches to ext package functions. Error handling propagates errors back to main() for stderr printing and exit code 1. The module uses context.Context for cancellation and relies on internal packages for core functionality.
