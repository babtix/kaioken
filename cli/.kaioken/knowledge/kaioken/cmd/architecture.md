The module centers around main.go, which defines the main function that parses command-line arguments, handles update notices, and dispatches to command-specific functions (e.g., cmdRun, cmdInit) based on the first argument. Each command is implemented in its own file (run.go, ext.go, etc.) and follows a pattern of accepting a context.Context and a flags struct containing parsed options (like -repo, -model, -force). Common operations such as loading configuration (via config.Load) and creating LLM clients (via newClient) are shared across commands. The module depends on numerous internal packages (e.g., internal/config, internal/llm, internal/agent) for actual functionality, keeping the command layer focused on argument parsing and workflow orchestration.
