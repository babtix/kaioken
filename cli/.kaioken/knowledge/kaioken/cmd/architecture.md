The main entry point is in main.go, containing the main function that performs global setup: cleaning up old binaries from self-update, determining interactivity for TUI mode, printing update notices, parsing arguments into a flags struct, setting up signal handling, and dispatching to command handlers via a switch statement. Each command handler (e.g., cmdRun, cmdInit) is a function accepting context.Context and flags, returning an error. Handlers typically load configuration via config.Load or setup.EnsureConfig, create an LLM client via newClient, execute core functionality by calling internal packages (agent, impact, etc.), and manage output (stdout/stderr, file writes). Error handling is centralized in main: errors are checked for errStale (exit code 1 without 'error:' prefix) or *cliExit (custom exit code), otherwise printed with 'error:' prefix and exit code 1. The bookSpend function records LLM usage post-execution. Commands with subcommands (ext, mcp) use the first positional as subcommand; command-specific flags not in the common set are parsed from positionals within handlers. The flags struct (defined in main.go) holds common flags (-repo, -model, etc.) and collects all positionals for command-specific use.
