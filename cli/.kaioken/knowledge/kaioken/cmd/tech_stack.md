The module uses the Go standard library for command-line parsing, file operations, and concurrency. It relies on the project's internal packages for core functionality: internal/config for configuration, internal/generate for knowledge card generation, internal/ext for extension management, internal/mcp for Model Context Protocol serving, internal/search for indexing and searching, internal/review for code review, internal/usage for spending tracking, internal/agent for the headless agent logic, internal/llm for LLM client interactions, and internal/session for session management. No external frameworks or libraries are used beyond the standard library and the project's own internal packages.
