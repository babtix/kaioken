The kaioken/config module manages application configuration for the Kaioken tool. It handles repository-specific configuration (.kaioken/config.yaml) that steers scanning, planning, and card generation, and global user configuration (~/.kaioken/config.yaml or $KAIOKEN_HOME/config.yaml) storing API keys, default provider/model, and user preferences. The module provides functions to load, save, and compute effective settings (e.g., concurrency limits for free-tier models) using YAML serialization.
