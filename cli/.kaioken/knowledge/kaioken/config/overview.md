The kaioken/config module manages application configuration for the Kaioken tool, handling both per-repository settings (stored in .kaioken/config.yaml) and global user settings (stored in ~/.kaioken/config.yaml or a custom path via KAIOKEN_HOME). It provides functions to load, validate, and save these configurations, including defaults for model selection, concurrency, and token limits, while enforcing security for API keys in the global config.
