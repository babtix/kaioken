The module consists of two source files: config.go and global.go. In config.go, the Config struct defines the per-repository configuration with fields for model, provider, concurrency, token limits, scope (include/exclude patterns), and notes. The Global struct in global.go holds user-specific settings such as default provider/model and a map of API keys per provider. Configuration loading is handled by Load() for repo configs and LoadGlobal() for global settings, which apply defaults and validate values (e.g., ensuring concurrency is at least 1). Saving is done via Save() methods on Config and Global, which write YAML files with descriptive headers and set appropriate file permissions (0o600 for global config to protect API keys). Key mechanisms include the IsFreeModel() function to detect free-tier models by the :free suffix and EffectiveConcurrency() method to adjust parallelism for free models to avoid rate limits. The module relies on gopkg.in/yaml.v3 for YAML serialization and standard library packages for file operations and string manipulation.
