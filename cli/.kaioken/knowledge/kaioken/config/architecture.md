The module consists of two source files: config.go and global.go. config.go defines the Config struct for per-repo settings, along with Scope, Memory, and Budget nested structs. It provides Default() to generate a baseline config, Load() to read and validate a repo's config.yaml, and Save() to write config back to disk. global.go defines the Global struct for user-wide settings (API keys, defaults) and provides LoadGlobal() and Save() methods.

Both use gopkg.in/yaml.v3 for YAML marshaling/unmarshaling. Configuration loading applies validations (e.g., minimum concurrency, maxModuleTokens) and uses DefaultExcludes to skip directories like .git and .kaioken. Error handling returns descriptive errors for missing or malformed files. Data flow: Load() reads file → unmarshals → applies defaults/validations → returns Config; Save() marshals struct → prepends header → writes file with appropriate permissions.
