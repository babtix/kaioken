The package defines two primary structs: Config for repository-specific configuration stored in .kaioken/config.yaml, and Global for user-global configuration stored in ~/.kaioken/config.yaml (or $KAIOKEN_HOME/config.yaml). Config loading (Load) reads and unmarshals YAML, applying defaults and validations (e.g., minimum concurrency). Global loading (LoadGlobal) returns an empty Global if missing. Saving operations create necessary directories: Config.Save uses 0o755 directories and 0o644 files, while Global.Save uses 0o700 directories and 0o600 files to protect API keys. Helper methods on Config (e.g., EffectiveConcurrency, LearnThreshold) derive runtime behavior from configuration values. The DefaultExcludes variable lists paths always skipped during scanning, including the config directory itself. The package uses gopkg.in/yaml.v3 for YAML processing and standard library filesystem operations.
