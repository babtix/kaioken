The module defines two primary configuration structs: Config (in config.go) for repository-specific settings and Global (in global.go) for user-wide settings. Config includes fields for model, provider, concurrency, token limits, scope, notes, memory, budget, search, prism, compaction, scoped models, theme, and per-role model overrides. Global includes default provider/model, API keys, extension registry, self-update settings, research configuration, search/prism defaults, and local endpoints. Configuration is serialized and deserialized using YAML (via gopkg.in/yaml.v3). Key functions include Default() for generating a default Config, Load(repo string) for reading and validating a repo's config, and Save() for writing config files. The Load function returns a helpful error if the config file is missing, prompting the user to run `kaioken init`. Tri-state boolean flags (unset, true, false) are implemented using pointers and helper methods (e.g., IsEnabled, GradeEnabled) that treat nil as enabled. The ResolveModel method on Config provides role-based model fallback to the session default model. EffectiveConcurrency adjusts parallelism for free-tier models to avoid rate limits. The module has no external dependencies beyond the standard library and the yaml package, and is intended to be imported by other parts of the application to access configuration values.
