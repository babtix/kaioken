The module consists of two primary files: config.go and global.go. config.go defines the Config struct and its methods, including Load and Save for repository-level configuration, as well as helper methods like ResolveModel for model selection per role and EffectiveConcurrency for adjusting concurrency based on model type. global.go defines the Global struct and its methods, including LoadGlobal and Save for user-level configuration, along with helper functions for determining the configuration file path and directory. Both configuration files are serialized and deserialized using the YAML format via the gopkg.in/yaml.v3 package. Error handling is performed through return values from file operations, with Load providing a specific error message when the configuration file is missing. The module does not implement authentication directly but relies on the global configuration to store API keys, which are used by other parts of the system. Data flow begins with loading configuration from disk into structs, which are then accessed by other modules via methods such as ResolveModel or LearnThreshold.
