The module consists of two primary files: config.go and global.go. config.go defines the Config struct for repository settings (including nested Scope, Memory, Budget, and Search structs) and provides Default(), Load(), Save(), Path(), EffectiveConcurrency(), and IsFreeModel() functions, plus methods like LearnThreshold() for memory aggression. global.go defines the Global struct for user-wide settings (including nested Research, SelfUpdate, Search, and LocalEndpoint structs) with GlobalPath(), GlobalDir(), LoadGlobal(), and Save() functions. Both use YAML via gopkg.in/yaml.v3. Loading returns helpful errors for missing repo configs (suggesting 'kaioken init') or empty defaults for global configs. Saving creates directories with appropriate permissions (0o755 for repo config dir, 0o700 for global config dir and 0o600 for the global file) and includes header comments. The module depends on the standard library and yaml package, with references to llm.Providers in comments indicating an external dependency.
