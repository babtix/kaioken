The program’s entry point is the `main` package in `./cmd/kaioken` (built by the Makefile target `build`). It initializes configuration from JSON files (`Kaioken-settings-logo.json` and `.claude/settings.local.json`), creates a `tea.Program` using a custom `bubbletea.Model`, and relies on Charmbracelet Bubbles for UI components (e.g., input, lists, spinners) and Lipgloss for styling. User actions produce `Msg` values that are processed in the `Update` method, which may invoke the clipboard via `github.com/atotto/clipboard`, parse `.gitignore` patterns with `github.com/sabhiram/go-gitignore`, load/save settings using `gopkg.in/yaml.v3`, and coordinate concurrent work with `golang.org/x/sync`. The view function renders the model into ANSI output using Lipgloss styles. Dependencies flow inward: `main` depends on the external libraries listed in `go.mod` and on internal packages (not shown) that encapsulate settings, UI, and assistant logic.
