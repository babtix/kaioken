The application entry point is in the ./cmd/kaioken package (referenced by the Makefile build target). The UI is built with charm/bubbletea and charm/bubbles components, while charm/glamour and charm/lipgloss handle markdown rendering and styling. Terminal I/O is managed via creack/pty (with github.com/UserExistsError/conpty for Windows PTY support). The system clipboard is accessed through github.com/atotto/clipboard. Project.Clipboard. File‑system ignore patterns are parsed with github.com/sabhiram/go-gitignore. A WebAssembly runtime (github.com/tetratelabs/wazero) is available for executing WASM‑based models or tools locally, and github.com/yuin/goldmark processes markdown. Configuration is loaded using gopkg.in/yaml.v3. Dependencies flow from the main package into these libraries; there is no visible internal layering beyond standard Go package organization.
