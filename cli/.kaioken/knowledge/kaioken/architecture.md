The application’s entry point resides in ./cmd/kaioken (built by the Makefile). The UI layer is built with github.com/charmbracelet/bubbletea and github.com/charmbracelet/bubbles components, while styling uses lipgloss and markdown rendering relies on goldmark and glamour. Terminal command execution is handled through github.com/UserExistsError/conpty and github.com/creack/pty to create pseudo‑terminals, with output captured and fed back into the TUI. System clipboard interactions use github.com/atotto/clipboard. Additional capabilities include PDF export via go-pdf/fpdf, WebAssembly execution via tetratelabs/wazero, and .gitignore parsing via sabhiram/go-gitignore. Data flow follows: user input → bubbletea update → command execution in a pty → output capture → rendering via glamour/lipgloss → display. Error handling follows standard Go error propagation; unit tests use stretchr/testify.
