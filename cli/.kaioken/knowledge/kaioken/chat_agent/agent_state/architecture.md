The module consists of two packages: session and state. The session package handles conversation persistence using a tree-structured JSONL format (v2) to support branching operations like forking, while maintaining backward compatibility with legacy JSON format. Sessions are saved as individual files in a repository's sessions directory, with each write updating the tree structure via syncTree() after Record(). The state package computes SHA256 hashes of module files (sorted by path) to detect changes, storing the results in a JSON state file. Dependencies flow from both packages to internal/config and, for session, to internal/llm; state additionally depends on internal/scan.
