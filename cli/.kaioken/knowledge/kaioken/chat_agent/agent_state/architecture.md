The session package (internal/session) defines Session and Meta structs, with functions to create sessions (New), record messages (Record), save/load/delete sessions (Save, Load, Delete), and list sessions (List). Sessions are stored as individual JSON files in <repo>/.ainow/sessions/, with IDs generated from timestamps and random numbers. The state package (internal/state) defines ModuleState and State structs, with Load/Save functions for persisting state to <repo>/.ainow/state.json and HashFiles for computing deterministic SHA256 hashes over sorted file paths and contents. Both packages depend on config for directory paths; session additionally depends on llm for Message types, while state depends on scan for File types. Error handling propagates file and JSON errors, with session.List skipping corrupt files to avoid hiding valid sessions.
