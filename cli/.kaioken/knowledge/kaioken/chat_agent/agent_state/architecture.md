The session package handles in-memory and disk-based conversation state. Sessions are stored as JSON files in <repo>/.ainow/sessions/ (config.Dir is ".ainow"). Key types: Session (holds messages, metadata, epochs, durable inbox), DurableInput (prompts awaiting processing), and Epoch (context change markers). Methods include New (ID generation), Record (updates transcript/title), AdmitInput/PromotePending (inbox management), Save/SaveForce (disk persistence), and Load/List (file I/O). The state package tracks per-module change detection via State.json in <repo>/.ainow/. It defines ModuleState (source hash, model, timestamp, file count, optional Git commit) and provides HashFiles (deterministic SHA256 over sorted file paths/content) and Load/Save (JSON file operations). Session depends on config and llm; state depends on config and scan. Data flow: session state flows to disk after each turn; state is read at startup to skip unchanged modules and written after generation.
