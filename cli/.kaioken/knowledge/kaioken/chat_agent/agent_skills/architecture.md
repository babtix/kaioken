The system's entry point is the Run function in internal/skills/generate.go, which orchestrates skill generation by building a code index, using an LLM to propose skill topics, and generating each skill's content in parallel. Each skill is represented by a Skill struct (defined in internal/skills/skills.go) containing metadata (name, description, sources, etc.) and a markdown body. Skills are saved as individual SKILL.md files under a repository's .kaioken/skills/ directory, with an accompanying README.md index generated by WriteIndex. Error handling isolates failures per skill (one failed skill does not halt the entire set), concurrency is managed via errgroup with limits from configuration, and staleness checking for incremental updates relies on the Sources field tracking files used to generate each skill.
