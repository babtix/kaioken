The system comprises two core components: skill generation (internal/skills/generate.go) and skill management (internal/skills/skills.go). Generation starts by building a code index via internal/codemap from scan results, then uses the LLM (internal/llm) to propose skill topics in the plan function. Each proposal is processed concurrently (limited by config.EffectiveConcurrency) through the write function, which generates the skill body via another LLM call. The Skill struct handles persistence: saving to .ainow/skills/<name>/SKILL.md with YAML frontmatter containing metadata (name, description, sources, etc.) and the markdown body. Management functions (List, Stale, WriteIndex) handle skill discovery, incremental regeneration based on file changes, and creating a skills index README.md. Dependencies flow inward: generation depends on codemap, config, llm, and scan; management depends on config and yaml.v3.
