- Skill names must be normalized to kebab-case using the Slug function (which converts to lowercase, trims spaces, replaces non-alphanumeric characters with dashes, and truncates to 60 characters).
- When persisting a skill, use the Skill.Save method which creates the skill's directory under .ainow/skills and writes the SKILL.md file.
- In concurrent skill generation (as in Run and Refresh), use an errgroup with a context for cancellation and set a concurrency limit via config.EffectiveConcurrency; individual skill errors should be logged and the goroutine should return nil to allow the group to continue.
- All functions must return errors as their last return value, and callers must handle them appropriately (e.g., checking for nil, logging, or propagating).
- When reading or parsing existing skill files, use the Load and Parse functions which handle files with or without YAML frontmatter (treating the latter as human-written skills).
