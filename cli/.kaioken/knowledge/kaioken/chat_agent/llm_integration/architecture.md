The module centers around the Client struct in openrouter.go which manages API key, base URL, model, HTTP client, usage tracking, and budget state. Key methods include Chat (simple completion), ChatWithTools (tool-assisted), and their streaming variants. The rawChat method handles HTTP requests with exponential backoff for 429/5xx errors and immediate retry on 402 errors using a learned token ceiling from budget.go. Budgeting dynamically adjusts max_tokens based on 402 responses to prevent credit exhaustion. Streaming (stream.go) processes server-sent events, assembling content and tool calls from fragments, and falls back to non-streaming if the provider rejects stream requests. Error handling includes special NVIDIA 404 fallback logic (trying model-specific URLs) and formatting 402 errors into user-friendly messages with remediation hints.
