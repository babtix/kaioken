The module centers around the Client struct in openrouter.go, which encapsulates provider configuration (API key, base URL, model, auth header, protocol) and HTTP client. Requests are routed through methods like Chat, ChatWithTools, and their streaming variants, which first convert messages to the provider's expected format (using helpers in anthropic.go for Anthropic's native API) before sending HTTP requests. Responses are parsed, with usage and cost tracked via recordUsage and CostUSD. Error handling includes retry logic with exponential backoff (retry.go), special handling for 402 credit errors (budget.go) that learns affordable token ceilings from provider responses, and NVIDIA-specific 404 fallbacks (openrouter.go) between generic and model-specific endpoints. Local providers (local.go) omit API key requirements and use extended timeouts for on-premise inference servers. Token estimation (tokens.go) uses a character-based heuristic for context window management, and streaming responses (stream.go) are processed via Server-Sent Events with fragment reassembly for tool calls.
