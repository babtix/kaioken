The llm_integration module provides a Go client for interacting with various LLM providers (OpenRouter, OpenAI, Anthropic, local models, etc.) with features including automatic retries, token budgeting, usage tracking, cost accounting, and support for both streaming and non-streaming responses. It handles provider-specific differences in authentication, request/response formats, and error conditions through a unified Client interface. Additionally, the module includes a model cost catalog for estimating costs when providers do not return actual cost, and supports reasoning levels (thinking) for certain providers.
