The module is written in Go and uses the standard library for concurrency (sync), context propagation, and string manipulation. It depends on internal packages: llm for LLM client interactions, events for the event bus, config and ext for configuration and extensions, skills and wiki for knowledge documentation, memory for project and user memory, prism for ModePrism functionality, and gitx for git worktree operations in the delegate tool. No external frameworks or libraries are used beyond the Go standard library and these internal packages.
