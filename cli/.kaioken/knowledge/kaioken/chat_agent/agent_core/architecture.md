The Agent struct holds the run's dependencies: LLM client, repository root, UI interface, configuration (mode, steps, etc.), budget guard, and event bus. The Run method (agent.go) drives the conversation: it prepares tools, gets a model response (with retry and streaming), processes tool calls (via tool_executor.go), and handles steering/follow-up queues. Context is managed by context.go (prompt assembly), ctxtrack.go (token estimation), epoch.go (prompt caching and change detection), and complemented by prune.go (tool result truncation) and compact.go (conversation summarization). Tool execution groups consecutive read-only calls for parallel processing, while other tools run sequentially, each wrapped by interceptable event hooks (ToolCall, ToolResult) for front-end intervention. Permissions for repo-changing actions are handled via the event bus (UI-driven approval), with standing permissions defined in permission.go. The agent emits lifecycle events (events.go) through a synchronous bus (events/bus.go) for decoupled observability, and reinforces mode-specific constraints each turn via reminders injected into the latest user message (reminders.go).
