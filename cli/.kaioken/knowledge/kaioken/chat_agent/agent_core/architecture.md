The agent core consists of agent.go (main Agent struct, Run loop, chat function, system prompt), tools.go (tool schemas, execution logic, path resolution, approval mechanism, undo tracking), diff.go (diff preview generation for approvals and structured diffs for UI), and knowledge.go (documentation catalog generation and serving). The Run loop in agent.go repeatedly calls chat (using llm.Client) until the model returns a final answer or steps are exhausted. For repo-changing tools (write_file, edit_file, run_command), execTool in tools.go resolves paths, generates previews via diff.go functions, seeks user approval via UI.Approve, applies changes, and records UndoEntry for potential undo. The read_knowledge tool serves documentation from .kaioken/ via knowledge.go's catalog and readCapped functions, with path confinement to prevent escapes. All file operations use the resolve method to confine paths to the repository root.
