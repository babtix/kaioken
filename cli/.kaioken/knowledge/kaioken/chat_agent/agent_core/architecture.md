The module centers around the Agent struct (agent.go) which drives the Run loop: preparing tools, calling the LLM via chatWithRetry, executing tool calls (with parallelism for read-only tools and approval hooks via the event bus), and processing steering/follow-up messages. Context management is handled by compact.go (compaction), prune.go (pruning), ctxtrack.go (token tracking), and reminders.go (per-turn reminders). The agent uses a dynamic tool registry (tool_registry.go) for runtime tools and accesses generated documentation via knowledge.go. Permission presets (mode.go) and standing permissions (permission.go) govern tool availability. Events (events/) decouple lifecycle moments, allowing interception of tool calls and results. BudgetGuard (budget.go) enforces session spending thresholds.
