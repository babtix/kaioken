The agent is centered around the Agent struct (agent.go) which holds an LLM client, UI interface, configuration, and dependencies like BudgetGuard, ContextTracker, and an event bus. The Run function (agent.go) drives the tool-calling loop: it calls the LLM (via chat or chatWithRetry), processes tool calls (tool_executor.go) with parallel execution for read-only tools and sequential for others, handles steering messages after each tool batch, and processes follow-up messages on final answers. Context is managed via compaction (compact.go) and pruning (prune.go) to stay within the model's window, while the BudgetGuard (budget.go) monitors session cost. The system prompt is assembled from multiple sources (context.go) and tracked by ContextEpoch (epoch.go) to detect changes. Permissions are enforced by a Ruleset (permission.go) that evaluates actions against wildcard patterns. Tool execution uses hooks (ToolCall, ToolResult) via the event bus (events/bus.go) to allow blocking or modifying calls and results. The agent also supports directory-scoped instructions (dirnotes.go), knowledge retrieval (knowledge.go), reminders (reminders.go), and sub-agent delegation (task.go).
