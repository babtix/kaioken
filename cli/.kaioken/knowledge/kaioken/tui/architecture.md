The TUI centers around a Model struct in tui.go holding state including configuration, conversation history, API keys, and UI components (viewport, textarea, spinner, list). User input is processed through the Update method handling key events, window resizes, and async messages from agent operations. Slash commands are defined in commands.go with matching logic for the palette (palette.go), which provides real-time autocompletion. Assistant responses are streamed via streamDeltaMsg and rendered as markdown using glamour (markdown.go) only upon completion. The sticky header (logo.go) displays live status (model, provider, repo) and remains fixed during transcript scrolling. Session persistence uses internal/session, and undo functionality relies on agent.UndoEntry. Key mechanisms include the command palette filtering via filterCommands, markdown rendering deferred until reply completion, and busy states showing spinners and elapsed time during long operations.
