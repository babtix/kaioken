The Model struct in tui.go holds state including repo, config, LLM client, conversation history, and UI modes (chat, picker, impact). User input is processed via the dispatch method, which routes slash commands to handlers (e.g., startImpact in impact.go, startResearch in research.go). Long-running operations run in goroutines, posting results via typed messages (impactMsg, doneMsg) on the events channel. The command palette (palette.go) provides autocomplete for the slash-command registry in commands.go. Styling is theme-driven via theme.go, and markdown replies are rendered by markdown.go using Glamour. Error handling uses predefined styles (errStyle, warnStyle) for consistent messaging.
