The TUI centers around a Model struct (tui.go) holding state like repo, config, LLM client, conversation history, and UI mode (chat, picker, impact tree). User input is dispatched via the Model.dispatch method to command-specific handlers (e.g., startResearch, doExt) returning Bubble Tea commands. The command palette (palette.go) filters slash commands from a registry (commands.go) in real-time. Assistant replies are rendered as markdown using glamour (markdown.go) with deferred rendering to avoid continuous reflow. A theme system (theme.go) manages ANSI colors, and a sticky header (logo.go) shows live status. Session branching uses tree.go, while impact predictions are viewed in an interactive tree (impacttree.go). Long-running operations guard against concurrency with a busy flag and communicate via an events channel.
