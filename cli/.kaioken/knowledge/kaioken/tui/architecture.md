The TUI centers around a Model struct (tui.go) implementing the Bubble Tea tea.Model interface, holding state like repository configuration, LLM client, session history, and UI components (viewport, textarea, spinner). User input is processed by the dispatch method, which routes slash commands to specific handlers (e.g., /ext in ext.go, /impact in impact.go) or treats non-command input as chat messages sent to the LLM via startChat. Long-running operations (research, extension install) run in goroutines communicating via m.events channel, updating UI with busy indicators and log messages. The command palette (palette.go) provides real-time autocompletion for slash commands, while markdown responses are rendered using glamour (markdown.go). Session management uses session package utilities for recording, saving, and switching branches (tree.go, sessions_ext.go). Theming is supported via dynamic style updates (theme.go). Key mechanisms include API key management per session to prevent leakage across providers (tui.go), error handling via styled output (lipgloss styles), and busy state guarding (m.guardBusy) to prevent concurrent operations. The TUI depends on internal packages (internal/llm, internal/session, internal/ext) and external libraries for UI and markdown processing.
