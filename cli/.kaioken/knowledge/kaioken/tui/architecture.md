The TUI centers around a Model struct (tui.go) holding state like repository config, LLM client, conversation history, and UI mode (chat, picker, impact). User input flows through the composer; typing '/' activates the palette (palette.go) which filters commands from the registry (commands.go) using prefix/substring matching. Command handlers (e.g., startResearch in research.go, startImpact in impact.go) are Methods on Model returning (tea.Model, tea.Cmd); long-running operations spawn goroutines communicating via m.events channel with busyMsg/logMsg/doneMsg. Rendering uses Bubble Tea components, Lipgloss for styling (theme.go), and a cached glamour renderer for markdown (markdown.go). Session state is managed via internal/session (sessions_ext.go), with error handling via appendLine and predefined styles (errStyle, okStyle).
