The module centers around a Model struct (tui.go) that holds application state including repository path, configuration, LLM client, conversation history, and UI state. User input is processed by the dispatch method (tui.go) which routes slash commands to specific handler functions (e.g., startImpact for /impact, startResearch for /research). The command palette (palette.go) provides real-time filtering and completion of slash commands from the registry defined in commands.go. Assistant replies are rendered as markdown using the glamour library (markdown.go) only after the full turn is received to avoid continuous reflow. The theme system (theme.go) allows switching between predefined color palettes. Session tree navigation (tree.go) enables branching and switching between conversation histories, while the impact tree (impacttree.go) displays interactive impact reports. Extensions are managed via the /ext command (ext.go) which interacts with the internal/ext package for installation, trust, and execution.
