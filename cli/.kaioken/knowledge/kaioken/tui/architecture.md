The TUI is structured around a Bubble Tea model (Model in tui.go) that manages state and handles user input via the Update method. The view is rendered by the View method. The TUI operates in three modes: modeChat (default), modePicker (for command and extension pickers), and modeImpact (for impact tree view).

User input is processed by the dispatch method (in tui.go) which routes slash commands to specific handlers (e.g., startImpact in impact.go, startResearch in research.go, doExt in ext.go). Non-slash input is sent as a chat message to the LLM client (llm.Client). Asynchronous operations (LLM calls, web searches, etc.) communicate results back to the TUI via channels (m.events) that trigger model updates.

The TUI uses a command registry (commands.go) to power the command palette (palette.go), which provides fuzzy matching and completion. Session management is handled via the session package, with branch visualization in tree.go. Extension management (ext.go) allows installing, trusting, and running community extensions. Styling is done with lipgloss, and markdown rendering with glamour.

Key mechanisms include API key storage (via /key command, saved to ~/.kaioken/config.yaml with 0600 permissions), error handling via errStyle-transcript messages, and busy state indication via busyMsg and spinner. The TUI depends on internal packages (llm, session, config, ext, impact, research, wiki, skills) and external libraries (bubbletea, lipgloss, glamour, clipboard).
