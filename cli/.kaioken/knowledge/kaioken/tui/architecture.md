The TUI module centers around the Bubble Tea Model defined in tui.go, which holds application state including repository path, configuration, API keys, LLM client, conversation history, and UI components (viewport, input, spinner, list). The UI is constructed using Bubble Tea components (textarea, textinput, spinner, list, viewport) and styled with Lipgloss, while Markdown rendering for assistant responses is handled by the glamour package via markdown.go.

User input is processed through the Update method, dispatching slash commands via the dispatch method. Slash commands are registered in commands.go as command structs, with matching and completion logic in the command.matches method and filterCommands function. The command palette UI is managed by the palette struct in palette.go. Long-running operations (e.g., extension installation, wiki generation) run in goroutines, communicating results via the Model's events channel using message types like doneMsg and logMsg.

The TUI depends on internal packages: agent for agent interactions and approval handling, config for configuration, ext for extension management, llm for LLM client, wiki and generate for knowledge engine operations, session for conversation persistence, and setup for initialization. Error handling displays styled messages via errStyle and warnStyle, with asynchronous errors reported through doneMsg. The Markdown renderer uses a mutex-protected cache to avoid reinitialization on every render, keyed by terminal width.
