The TUI is structured around a central `Model` struct (in tui.go) that manages state and implements the Bubble Tea update loop. User input is processed via the `dispatch` method, which routes slash commands to handler functions (e.g., `doWiki`, `doPlan`) defined in the same file. The command registry, defined in commands.go, provides the `command` struct and matching logic for the palette interface. The TUI depends on internal packages for core functionality: `internal/agent` for agent operations, `internal/config` for configuration, `internal/llm` for language model interactions, `internal/session` for conversation history, and `internal/wiki` for knowledge base operations. Key mechanisms include API key handling via the `/key` command (stored globally in ~/.kaioken/config.yaml), error handling through styled transcript lines (using `errStyle` and `logMsg`), and state management for modes (chat, picker, impact) to switch between views like the command palette and impact tree.
