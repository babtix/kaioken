The TUI module uses the Bubble Tea library (github.com/charmbracelet/bubbletea) for the UI framework, Lipgloss (github.com/charmbracelet/lipgloss) for terminal styling, and Glamour (github.com/charmbracelet/glamour) for markdown rendering. It also depends on internal packages including llm for language model interaction, impact for impact prediction, research for web search, ext for extension management, session for session handling, and config for configuration management.
