The tui module uses the Bubble Tea library (github.com/charmbracelet/bubbletea) for the terminal UI framework, Lipgloss (github.com/charmbracelet/lipgloss) for styling, and various Bubble Tea components including key, list, spinner, textarea, textinput, and viewport. It also uses the atotto/clipboard package for clipboard operations and github.com/charmbracelet/glamour for markdown rendering.
