The TUI uses github.com/charmbracelet/bubbletea for the UI framework, github.com/charmbracelet/lipgloss for styling, and github.com/charmbracelet/glamour for markdown rendering. It depends on internal packages: kaioken/internal/llm (LLM client), kaioken/internal/impact (impact prediction), kaioken/internal/research (web research), kaioken/internal/ext (extension management), and kaioken/internal/session (session handling).
