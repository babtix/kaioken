The module uses the Bubble Tea framework (github.com/charmbracelet/bubbletea) with its subpackages (key, list, spinner, textarea, textinput, viewport), Lipgloss for styling (github.com/charmbracelet/lipgloss), Clipboard for clipboard access (github.com/atotto/clipboard), Glamour for markdown rendering (github.com/charmbracelet/glamour), and YAML for extension manifests (gopkg.in/yaml.v3).
