The TUI uses the Bubble Tea framework (`github.com/charmbracelet/bubbletea`) and its components (textarea, textinput, spinner, list, viewport) for terminal UI. It relies on `lipgloss` for styling and `glamour` for markdown rendering. Internally, it depends on Kaioken packages for agent logic (`agent`, `llm`), configuration (`config`), extensions (`ext`), and knowledge engine (`wiki`, `scan`, `plan`, `cards`, `skills`).
