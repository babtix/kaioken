The TUI module relies on the Bubble Tea framework (github.com/charmbracelet/bubbletea) for UI components, Lipgloss (github.com/charmbracelet/lipgloss) for styling, Glamour (github.com/charmbracelet/glamour) for markdown rendering, and the clipboard package (github.com/atotto/clipboard) for system clipboard access. It integrates with internal packages including agent, config, generate, gitx, llm, plan, scan, serve, session, skills, state, version, and wiki to provide agent interactions, knowledge engine pipelines, and session management.
