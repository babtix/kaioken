The TUI module uses the Bubble Tea library (`github.com/charmbracelet/bubbletea`) for terminal UI management, Lipgloss (`github.com/charmbracelet/lipgloss`) for styling, and Glamour (`github.com/charmbracelet/glamour`) for markdown rendering of assistant replies. It also relies on the atotto/clipboard package (`github.com/atotto/clipboard`) for clipboard access and the standard library for core functionality.
