The TUI module uses the Bubble Tea framework (github.com/charmbracelet/bubbletea) for the terminal UI, along with Bubbles components (textarea, textinput, spinner, list, viewport) and Lipgloss for styling. Markdown rendering is handled by the github.com/charmbracelet/glamour package. It depends on internal Kaioken packages for configuration (config), agent interactions (agent), extension management (ext), LLM interactions (llm), and knowledge engine operations (wiki, generate, session, setup).
