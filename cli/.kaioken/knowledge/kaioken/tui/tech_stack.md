The TUI module uses the Bubble Tea library (github.com/charmbracelet/bubbletea) for the terminal UI framework and Lip Gloss (github.com/charmbracelet/lipgloss) for styling. It also relies on Bubble Tea components (github.com/charmbracelet/bubbles) for interactive widgets, the clipboard library (github.com/atotto/clipboard) for system clipboard access, and Glamour (github.com/charmbracelet/glamour) for markdown rendering in the terminal.
