The module consists of five source files: gitx.go (core Git operations like IsRepo, Head, Changes, Patch), hook.go (post-commit hook installation and removal), status.go (detailed file status tracking), work.go (staging, committing, diffing, and line statistics), and worktree.go (isolated worktree operations). Core functions in gitx.go, status.go, and work.go depend on the run and runRaw helpers to execute Git commands, propagating context for cancellation. Hook management preserves existing hook content by inserting a delimited block (marked by hookStart and hookEnd) and uses shell-quoted paths for cross-platform compatibility. Worktree functions create temporary detached checkouts, generate patches from them, apply patches to the main repo, and clean up the worktree directory. Error handling consistently wraps Git command errors with context, and path normalization ensures consistent handling of file paths across operating systems.
