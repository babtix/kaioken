The module consists of five Go files: gitx.go (core Git operations like Head, Changes, Patch), hook.go (post-commit hook installation/removal), status.go (detailed file status), work.go (staging, unstaging, discarding, committing), and worktree.go (isolated worktree operations). Core functions use run/raw helpers that execute git via exec.CommandContext, capturing stdout/stderr and wrapping errors. Most Git-operation functions take context.Context for cancellation; IsRepo/Branch/DirtyCount use context.Background() internally. Paths are normalized to slash-separated repo-relative form using filepath.ToSlash for returns and filepath.FromSlash for filesystem access. Hook management preserves existing hook content while inserting/removing a delimited block (marked by # >>> kaioken >>>/# <<< kaioken <<<) and runs the update command detached (&) to avoid blocking commits. Error handling returns errors from git command failures, with specific errors like ErrNoPaths for empty path lists.
