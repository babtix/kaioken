The gitx package is organized into four source files grouping related functionality: gitx.go for low-level git command execution and high-level change detection, hook.go for managing the post-commit git hook to trigger wiki updates, status.go for detailed file status reporting, and work.go for staging, unstaging, discarding, committing, and diff operations. All files are in the same package, allowing internal function calls (e.g., work.go functions call gitx.go's run, Head, HasCommit, and Status functions). The package centers around the run function, which executes git commands in a given repository directory and handles error formatting. There is no explicit caching or authentication; the package relies on the system's git installation and the repository's state. Context propagation is used for cancellable git operations where appropriate (e.g., in Head, Resolve, Changes, Patch, Subjects, Stage, Unstage, Discard, Commit, FileDiff, LineStats, Upstream), while simpler checks like IsRepo use context.Background() internally.
