The package is organized into several files each handling a distinct aspect of Git operations. gitx.go contains core functions like Head, Root, Changes, and Patch. hook.go manages the installation and removal of a post-commit hook that triggers a Kaioken update. status.go defines the FileStatus struct and provides a parsed status from git status --porcelain. work.go includes staging, unstaging, discarding, committing, and diff operations. worktree.go supports creating temporary worktrees, generating patches from them, and applying those patches. All functions depend on the git executable being available and use context for cancellation where applicable. Error handling wraps git command failures with contextual messages, and path handling ensures cross-platform consistency by converting to slash-separated paths internally.
