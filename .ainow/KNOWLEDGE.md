# Project Knowledge Base

Generated by ainow. Read this index, then open the cards for the
modules relevant to your task. Cards: `overview.md`, `architecture.md`,
`conventions.md`, `tech_stack.md`, and sometimes `setup_commands.md`.

- **ainow — Terminal AI Coding Assistant & Knowledge Engine** — Single Go binary providing an interactive TUI chat agent and a knowledge engine that scans repos, plans modules, and generates knowledge cards. _(not generated yet)_
  - **CLI Entry Point** — Main command dispatcher wiring subcommands (init, scan, plan, generate, update, status, tui) and the bare TUI launch. _(not generated yet)_
  - **Terminal UI (Bubble Tea)** — Interactive terminal interface with slash-commands, live streaming progress, model picker, diff approval prompts, and multi-pane layout. _(not generated yet)_
  - **Chat Agent & Tool Execution** — Core agent loop that converses with the LLM, executes tool calls (read_file, list_files, search, write_file, edit_file, run_command), and presents diffs for approval. _(not generated yet)_
  - **LLM Provider Abstraction** — Provider-agnostic client for OpenAI-compatible endpoints (OpenRouter, OpenAI, Groq, Together, DeepSeek, Mistral, Ollama) with live model catalog fetching. _(not generated yet)_
  - **Repository Scanner** — Walks the target repo respecting .gitignore, builds a file inventory, and extracts symbols/structure for downstream planning. _(not generated yet)_
  - **Module Planner** — Uses an LLM to propose a hierarchical module tree (modules.yaml) from the scan inventory, with human-in-the-loop editing before generation. _(not generated yet)_
  - **Knowledge Card Generator** — Parallel generation of dense knowledge cards per module (overview, architecture, conventions, tech_stack, setup_commands) with incremental rebuilds via content hashes. _(not generated yet)_
  - **Configuration Management** — Loads and merges .ainow/config.yaml (model, excludes, steering notes) with CLI flags and environment variables. _(not generated yet)_
  - **State Persistence** — Manages .ainow/state.json tracking per-module source hashes to enable incremental updates and freshness status. _(not generated yet)_
