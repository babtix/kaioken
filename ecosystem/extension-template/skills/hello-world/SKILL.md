# Hello, world

This skill exists to show the format. A real skill teaches an agent how to
perform one recurring task well: which files to touch, in what order,
following which conventions.

## Steps

1. Say hello.
2. Replace this skill with something your project actually needs — the
   frontmatter `description` is what the agent matches on, so make it say
   plainly *when* to load the skill.

## Notes

- One directory under `skills/` per skill, each with a `SKILL.md`.
- Keep skills short and procedural. The agent reads them mid-task.
